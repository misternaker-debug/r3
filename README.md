## Описание проекта
В этой работе моей целью является повышение производительности LLM в доменной области – геофизика. Для решения этой задачи был выбран подход описанный в статье https://arxiv.org/pdf/2505.24726

GRPO R³ — это модификация GRPO для улучшения языковых моделей через обучение с подкреплением, комбинирующая метод GRPO с подходом self-reflection. 
Сначала модели предлагается выполнить задачу. Если она справляется, мы ничего не делаем, так как модель уже соответствует нашим требованиям. Если же она не справляется, мы предлагаем ей проанализировать, что могло пойти не так.

В целях повышении эффективности мы не обучали модель на полном наборе данных, а подготовили датасет ошибок модели. для каждого промта мы попросили модель сгенерировать несколько ответов.

После обучения модель Qwen3-1.7B показала улучешения в метриках: средняя интегральная точность до 66.61% (на 10,93), средний интегральный балл до 67.18% (на 16,45) на бенчмарках. 

## Ход решения
- Предобработка данных.
- Реализация функции награды.
- Обучение модели с помощью GRPOTrainer.
- Создание датасета ошибок
- Модификация GRPOTrainer
- Обучение модели рефлексии.

## Использование

Сначала необходимо сгенерировать датасет ошибок, а потом на нём обучить модель с помощью модификации GRPO.
Аргументы:
- `file_path` — путь до датасета.
- `model_name` — модель.
- `num_responses_per_prompt` — количество сгенерированных ответов на одну задачу.


Пример скрипта для генерации датасета: `python src/create_failures.py data.json Qwen/Qwen3-1.7B 64`
